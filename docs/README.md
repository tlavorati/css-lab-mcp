# Docs assets

The images in this folder were generated by css-lab itself with `--screenshot`:

- `stacking-bug-before.png`: `inspect` on `examples/stacking-bug/before.html` with the menu open.
  The target ("Delete") is outlined in green and the occluder (the next card's header) in red.
- `stacking-bug-after.png`: the same command on `after.html`, where the target is clickable.
- `invisible-blockers.png`: `scan` on `test/fixtures/invisible-blockers.html`, with the three
  invisible blockers outlined in red.

Regenerate the PNGs:

```bash
npm run build
S=".card:nth-child(1) .menu-item.danger"
node dist/cli.js inspect examples/stacking-bug/before.html -s "$S" --pre "click:.card:nth-child(1) .menu-toggle" --viewport desktop --screenshot docs/stacking-bug-before.png
node dist/cli.js inspect examples/stacking-bug/after.html  -s "$S" --pre "click:.card:nth-child(1) .menu-toggle" --viewport desktop --screenshot docs/stacking-bug-after.png
node dist/cli.js scan test/fixtures/invisible-blockers.html --viewport desktop --screenshot docs/invisible-blockers.png
```
